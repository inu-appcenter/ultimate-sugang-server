## Implementation

신청 요청은 들어오는 대로 바로 정원 검사와 저장을 시도했고, 시작 시각에 요청이 몰리면 커넥션 풀이 바닥나 뒤의 요청이 실패했습니다.

<br>

1. 신청 요청이 들어오면 회원별 대기 순번을 발급하고, 한 번에 처리할 수 있는 수만큼만 신청 처리로 넘기도록 했습니다.
2. 남은 순번을 조회하는 API를 두어 화면이 대기 상태를 보여줄 수 있게 했습니다.
3. 동시 500명 부하에서 p95가 4.2초에서 0.8초로 줄고 실패율이 18%에서 0%가 된 것을 확인해 기본 처리량을 초당 200건으로 정했습니다.

<br>

> [!NOTE]
> Plan과 달라진 점: 순번을 받은 뒤 화면을 떠난 회원이 자리를 계속 차지해, 일정 시간 조회가 없는 순번은 만료하도록 했습니다.
