## Issue

수강신청 시작 시각에 신청 요청이 한꺼번에 몰리면 커넥션 풀이 바로 바닥나고, 뒤에 들어온 요청은 대기 시간 초과로 실패한다.

<br>

실제 수강신청에서는 대기 순번이 보이지만 시뮬레이터에는 그 단계가 없어, 연습하는 흐름이 실제와 어긋난다.

<br>

> [!NOTE]
> 근거: 신청 API 부하 측정(동시 500명, p95 4.2초, 실패율 18%)

<br>

## Plan

- [ ] 신청 요청에 회원별 대기 순번을 발급하고, 차례가 된 요청만 신청을 처리
- [ ] 남은 순번을 조회하는 API를 두어 화면이 대기 상태를 보여줄 수 있게 함
- [ ] 대기열 길이와 처리 속도를 부하 테스트로 측정해 기본 처리량을 정함
